# Moyang Wang — personal website

Static personal website, published with GitHub Pages.

- `index.html`: biography, research, project, coursework, and life.
- `research.html`: research overview and experimental lessons.
- `style.css`: responsive styles.
- `resume.pdf`: downloadable one-page CV.
- `assets/`: selected personal photographs.

To edit, change the HTML/CSS and push to `main`. No build dependencies.
